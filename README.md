# 微信语音桥（Dictation Bridge）

微信语音桥是一款 Windows 小工具，用于将本机微信的语音听写结果输入到远程桌面、远程控制软件或其他本地应用的文本框中。

当远控软件占据焦点时，微信听写快捷键往往无法在本机触发。本工具通过临时接收微信听写结果，再将文字回填到原来的目标窗口，让你可以直接对着本机麦克风说话，在远程电脑中输入中文。

$10.0.4`

## 主要功能

- 按住悬浮按钮开始微信语音听写，松开后结束。
- 自动记住听写前的目标窗口。
- 等待识别结果稳定后，自动切回目标窗口并粘贴文字。
- 主窗口始终保留识别结果，自动粘贴失败时可以手动复制。
- 不注入微信进程，不读取微信内存，也不调用微信私有接口。

## 使用要求

- Windows 10 或 Windows 11。
- 已安装并登录支持语音输入功能的电脑版微信。
- 手动按住 `Ctrl+Win` 时，微信语音输入能够正常工作。
- 微信语音识别服务自身需要可用的网络连接。

## 使用方法

1. 启动微信并保持登录。
2. 运行微信听写桥。
3. 在远程控制窗口或其他目标应用中点击需要输入文字的位置。
4. 按住屏幕右上角的绿色悬浮按钮并说话。
5. 说完后松开按钮。
6. 程序收到稳定的识别结果后，会自动返回原目标窗口并发送粘贴指令。

如果自动粘贴失败，识别文字仍会保留在主窗口。点击“复制结果”，再手动切换到目标位置粘贴即可。

## 工作原理与限制

微信听写桥会在开始听写时临时激活自己的文本框，使本机微信能够接收 `Ctrl+Win` 快捷键并写入识别结果。识别结束后，程序把文字写入 Windows 剪贴板、恢复原目标窗口，然后发送 `Ctrl+V`。

由于不同远控软件对模拟按键的处理方式不同，直接发送 Unicode 字符并不通用，因此当前版本使用剪贴板作为兼容性最好的文字传输方式。

请注意：

- 每次自动回填都会用本次听写结果覆盖当前剪贴板内容。
- 某些远控软件可能禁止剪贴板同步或模拟按键，此时自动回填可能失败。
- 本工具本身不会联网，但微信听写功能由微信提供，其联网行为和隐私规则以微信为准。

## 下载

请从仓库的 [Releases](https://github.com/lsby/wechat-dictation-bridge/releases) 页面下载最新的 Windows x64 单文件版本。发布页面同时提供 SHA-256 校验文件。

## 从源码构建

需要安装 .NET 9 SDK：

```powershell
dotnet build .\WechatDictationProbe.csproj -c Release
```

发布 Windows x64 单文件版本：

```powershell
dotnet publish .\WechatDictationProbe.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o .\dist
```

## 发布新版本

1. 修改 `WechatDictationProbe.csproj` 中唯一的 `<Version>`，格式为 `x.y.z`。
2. 提交并推送到 `main` 分支。
3. GitHub Actions 会在对应的 `v<Version>` 标签尚不存在时，自动构建程序并创建 GitHub Release。

相同版本不会重复发布。
